# Correspondance OWASP Top 10 (2021)

Dérivée de l'audit de sécurité réel (Phase 1, cf. `CHANGELOG.md`) et du code — chaque ligne pointe vers un fichier et, quand il existe, un test.

| # | Catégorie | Mesure(s) réelle(s) | Fichier(s) | Test(s) |
|---|---|---|---|---|
| A01 | Broken Access Control | Fonction d'autorisation centrale (`autoriser()`) et vérifications d'appartenance par ressource (rôle **et** propriétaire) sur charges, incidents, votes ; jamais de filtrage côté client seul | `services/autorisation.service.ts`, `services/charge.service.ts`, `services/incident.service.ts`, `services/vote.service.ts` | `autorisation.service.test.ts` (matrice complète) ; tests d'intégration négatifs sur chaque route sensible |
| A02 | Cryptographic Failures | Mots de passe bcrypt (facteur 12) ; jetons de réinitialisation empreinte SHA-256 uniquement ; cookie de session signé HMAC-SHA256, comparaison à temps constant (`timingSafeEqual`) ; HTTPS obligatoire en production (Caddy, Let's Encrypt) | `services/mot-de-passe.service.ts`, `services/session.service.ts`, `deploy/Caddyfile` | `mot-de-passe.service.test.ts`, `session.service.test.ts` |
| A03 | Injection | 100 % des accès base via Prisma paramétré (aucune concaténation SQL) ; validation Zod systématique sur chaque endpoint ; refus de `<`/`>` sur les champs texte d'incident (défense en profondeur pour un futur export non échappé) ; React échappe tout rendu par défaut (0 `dangerouslySetInnerHTML` dans le code) | tous les contrôleurs (`z.object(...).safeParse`) | vérifié par grep exhaustif (Phase 1 de l'audit), tests d'intégration sur entrées invalides |
| A04 | Insecure Design | Modèle de menace STRIDE formalisé dès la conception (Doc 5) ; matrice d'autorisation par ressource définie avant l'implémentation ; immutabilité des votes après clôture garantie au niveau schéma (clé composite), pas seulement applicative | `docs/08-security/README.md` § STRIDE, migration `0001_init` | `contraintes-base.integration.test.ts` |
| A05 | Security Misconfiguration | En-têtes de sécurité explicites (Helmet configuré, pas seulement les valeurs par défaut : CSP stricte, `X-Frame-Options: DENY`) ; CORS à liste blanche fixe (jamais de wildcard) ; base et backend non exposés publiquement en production (seul Caddy publie un port) | `apps/backend/src/app.ts`, `docker-compose.prod.yml` | `security-headers.test.ts` |
| A06 | Vulnerable and Outdated Components | `npm audit` intégré à la CI (`--audit-level=high`), exécuté à chaque push ; dépendances retenues ou écartées après vérification de leur arbre (ex. `nyc`/`autocannon` écartés au profit d'un script sans dépendance après détection d'une vulnérabilité transitive) | `.github/workflows/ci.yml` | job `quality`, étape « Audit de sécurité des dépendances » |
| A07 | Identification and Authentication Failures | Rate limiting par IP **et** par compte sur la connexion (NF-05) ; anti-énumération (réponse identique compte existant/inexistant) ; révocation de session à la déconnexion et au changement de mot de passe, partagée entre instances via Redis | `controllers/auth.controller.ts`, `repositories/redis-client.ts` | `auth-limite.integration.test.ts`, `session-invalidation.integration.test.ts`, `redis-partage.integration.test.ts` |
| A08 | Software and Data Integrity Failures | CI/CD qui construit, teste et vérifie les images avant publication (registre de conteneurs) ; migrations de base versionnées et vérifiées sans dérive (`prisma:drift`) ; aucune dépendance chargée depuis une source non contrôlée (polices auto-hébergées, pas de CDN tiers) | `.github/workflows/ci.yml` (job `livraison`), `prisma:drift` | vérifié à chaque run CI |
| A09 | Security Logging and Monitoring Failures | Journalisation des actions sensibles (connexion, vote, clôture d'AG, changement de statut d'incident) en JSON structuré, **sans** donnée personnelle ni valeur de vote (F-11) | `services/journal.service.ts` | `journal.service.test.ts` |
| A10 | Server-Side Request Forgery (SSRF) | Aucun endpoint de l'application n'effectue de requête sortante vers une URL fournie par l'utilisateur (pas d'aperçu de lien, pas de webhook configurable) — catégorie non applicable au périmètre actuel, vérifié par relecture des endpoints plutôt que supposé | — | — |
